    Class 2.4 - 组合数据类型¶

    组合数据类型，其实就相当于是容器一样，可以用来存储多个数据

    • 常见的组合数据类型有列表、元组、集合、字典
    • 我们本节来详细介绍一下这几种组合数据类型的常用方法，以及它们之间的相互转换

    1. 列表¶

    (1) 列表的基本概念¶

    (a) 列表的定义¶

    列表 (list) 是 Python 中的一种有序的并且可变的组合数据类型，可以用来存储一组相关的数据。

    • 列表的定义是用一对方括号 [] 把数据括起来，数据之间用逗号 , 分隔:
    fruits = ["apple", "banana", "cherry"]
print(fruits)
print(type(fruits))

    ['apple', 'banana', 'cherry']
<class 'list'>
    • 如果想要定义一个空列表，可以直接使用一对空的方括号 []，或者使用 list() 函数:
    empty_list1 = []
empty_list2 = list()
print(empty_list1)
print(empty_list2)
print(type(empty_list1))
print(type(empty_list2))

    []
[]
<class 'list'>
<class 'list'>

    (b) 列表的元素¶

    列表中的每个数据项称为元素 (element):

    • 列表中的元素可以是任意Python中的数据类型，包括数字、字符串、布尔值，甚至其他组合数据类型
    • 列表中的元素在定义时还可以放入之前定义过的变量
    a = 10
mixed_list = [a, 1, "apple", 3.14, True, None, [1, 2, 3], (4, 5)]
print(mixed_list)

    [10, 1, 'apple', 3.14, True, None, [1, 2, 3], (4, 5)]

    (c) 列表的索引与切片¶

    列表的元素是有序排列的，因此可以进行索引与切片操作，并且列表的切片与字符串的切片操作是类似的：

    • 索引格式为 列表[索引]，其中正数索引从 0 开始，负数索引从 -1 开始
    • 切片格式为 列表[开始索引:结束索引:步长]

    例如我们定义一个姓名列表：

    张三 李四 王五 赵六 牛七 马八 陈九
    正向索引 0 1 2 3 4 5 6
    反向索引 -7 -6 -5 -4 -3 -2 -1 
    name = ["张三", "李四", "王五", "赵六", "牛七", "马八", "陈九"]
print(name[0]) 
print(name[-1])
print(name[1:4])
print(name[::2])
print(name[::-1])

    张三
陈九
['李四', '王五', '赵六']
['张三', '王五', '牛七', '陈九']
['陈九', '马八', '牛七', '赵六', '王五', '李四', '张三']

    (d) 列表元素的修改¶

    列表是可变的，也就是说，我们可以通过索引找到列表中的某个元素，再给它重新赋值，来修改这个元素：

    • 修改的格式是 列表[索引] = 新值
    scores = [90, 85, 70]
scores[1] = 88
print(scores)

    [90, 88, 70]

    (e) 嵌套列表¶

    前面我们提到，列表中的元素可以是任意类型的数据，包括另一个列表。列表中又包含列表的结构，就叫做嵌套列表：

    • 取嵌套列表中的元素，需要连续使用两次索引：第一个索引找到里面的某个列表，第二个索引再找到这个列表中的元素
    • 嵌套列表常常用来表示二维的表格，其中每一个内层的列表就是表格中的一行
    table = [
    ["Alice", 25, 95],
    ["Bob", 36, 88],
    ["Charlie", 25, 76]
]

print(table[1])
print(table[1][0])
print(table[2][-1])

    ['Bob', 36, 88]
Bob
76

    (2) 列表的常用操作¶

    (a) 列表的拼接与重复¶

    列表的拼接与重复操作与字符串类似，使用 + 和 * 运算符：

    • 两个列表之间可以使用 + 进行拼接
    • 一个列表可以 * 另一个整数进行重复
    list1 = [1, 2, 3]
list2 = ["a", "b", "c"]
print(list1 + list2)
print(list1 * 2)

    [1, 2, 3, 'a', 'b', 'c']
[1, 2, 3, 1, 2, 3]

    (b) 列表的成分判断¶

    列表的成分判断与字符串类似，使用 in 和 not in 运算符：

    • 使用 in 判断某个元素是否在列表中
    • 使用 not in 判断某个元素是否不在列表中
    list3 = [1, 2, 3, "a", "b", "c"]
print(2 in list3)
print("d" not in list3)

    True
True

    (c) 列表的常用函数¶

    列表的常用函数有：

    • len(列表)：返回列表的长度（元素个数）
    • max(列表)：返回列表中的最大值（列表元素需全部为数字类型）
    • min(列表)：返回列表中的最小值（列表元素需全部为数字类型）
    • sum(列表)：返回列表中所有元素的和（列表元素需全部为数字类型）
    • sorted(列表)：返回一个排序后的新列表，原列表不变
    list_num = [3, 1, 4, 1, 5, 9, 2, 6, 5]

print(len(list_num))
print(max(list_num))
print(min(list_num))
print(sum(list_num))
print(sorted(list_num))

    9
9
1
36
[1, 1, 2, 3, 4, 5, 5, 6, 9]

    (d) 列表的常用方法¶

    列表的常用方法有很多，我们不可能全部介绍，这里我们介绍一些常用的：

    • 列表.append(元素)：在列表末尾添加一个元素
    • 列表.extend(可迭代对象)：在列表末尾一次性追加另一个可迭代对象中的多个元素
    list_new1 = [1, 2, 3]
list_new1.append(4)
print(list_new1)

list_new1.extend([5, 6, 7])
print(list_new1)

    [1, 2, 3, 4]
[1, 2, 3, 4, 5, 6, 7]
    • 列表.remove(元素)：删除列表中第一个匹配的指定元素
    list_new2 = [0, 1, 2, 3, 4, 5, 6, 7]
list_new2.remove(3)
print(list_new2)

    [0, 1, 2, 4, 5, 6, 7]
    • 列表.insert(索引, 元素)：在指定索引的位置插入一个元素
    • 列表.pop(索引)：删除指定索引位置的元素，并返回这个被删除的元素，如果不写索引，则默认删除最后一个元素
    list_new3 = [1, 2, 3]
list_new3.insert(1, 99)
print(list_new3)

removed = list_new3.pop()
print(removed)
print(list_new3)

    [1, 99, 2, 3]
3
[1, 99, 2]
    • 列表.index(元素)：返回元素第一次出现的索引
    • 列表.count(元素)：返回元素在列表中出现的次数
    list_new4 = [3, 1, 4, 1, 5]
print(list_new4.index(4))
print(list_new4.count(1))

    2
2
    • 列表.sort(reverse=False)：对列表进行原地排序，reverse 参数指定是否降序
    • 列表.reverse()：将列表中的元素反转
    list_new5 = [3, 1, 4, 1, 5, 9, 2, 6, 5]
list_new5.sort()
print(list_new5)

list_new5.sort(reverse=True)
print(list_new5)

list_new5.reverse()
print(list_new5)

    [1, 1, 2, 3, 4, 5, 5, 6, 9]
[9, 6, 5, 5, 4, 3, 2, 1, 1]
[1, 1, 2, 3, 4, 5, 5, 6, 9]

    (e) 重要：列表方法的返回值¶

    我们来看一下以下操作：

    list_a = [3, 1, 4, 1, 5, 9, 2, 6, 5]
list_b = list_a.sort()
print(list_a)
print(list_b)

    [1, 1, 2, 3, 4, 5, 5, 6, 9]
None

    这里我们看到 list_a 被排序了，但是 list_b 的值却是 None

    • 这是因为 sort() 方法是原地排序，不会返回新的列表，而是直接对原列表进行修改，因此它的返回值是 None， 就是什么也不返回

    • 因此，使用一个变量来接受 sort() 方法的返回值是没有意义的

    • 这就是 Python 中函数与方法的 返回值 的概念，后面我们会反复看到，有些操作会返回一个新的值，而有些操作则是在原值上修改不会返回任何值（返回 None）

    • 这和上一节学过的字符串方法不同：字符串是不可变的，字符串的方法不会修改原来的字符串，而是返回一个新的字符串；而列表是可变的，sort() 这样的方法会直接修改原来的列表

    2. 元组¶

    (1) 元组的基本概念¶

    (a) 元组的定义¶

    元组 (tuple) 是 Python 中的一种有序的但不可变的组合数据类型，可以用来存储一组相关的数据。

    • 元组的定义是用一对圆括号 () 把数据括起来，数据之间用逗号 , 分隔:
    fruits = ("apple", "banana", "cherry")
print(fruits)
print(type(fruits))

    ('apple', 'banana', 'cherry')
<class 'tuple'>
    • 如果想要定义一个空元组，可以直接使用一对空的圆括号 ()，或者使用 tuple() 函数:
    empty_tuple1 = ()
empty_tuple2 = tuple()
print(empty_tuple1)
print(empty_tuple2)
print(type(empty_tuple1))
print(type(empty_tuple2))

    ()
()
<class 'tuple'>
<class 'tuple'>
    • 如果想要定义一个只有一个元素的元组，需要在元素后面加上逗号 ,，否则 Python 会把它当作普通的括号表达式:
    single_element_tuple1 = (42,)
single_element_tuple2 = (42)
print(single_element_tuple1)
print(single_element_tuple2)
print(type(single_element_tuple1))
print(type(single_element_tuple2))

    (42,)
42
<class 'tuple'>
<class 'int'>

    注意，由于元组是不可变的，因此所有修改元组的操作，包括添加、删除或修改元素，都是不支持的，这些操作会引发 TypeError 错误

    • 唯一修改元组的方法，就是重新定义这个元组
    fruits = ("apple", "banana", "cherry")
# fruits[0] = "orange"  # 这行代码会引发 TypeError 错误
print(fruits)

fruits = ("orange", "banana", "cherry")  # 重新定义元组
print(fruits)

    ('apple', 'banana', 'cherry')
('orange', 'banana', 'cherry')
    • 因此，元组这里的知识点比较简单，只包括索引与切片等操作

    (b) 元组的常见操作¶

    由于元组是有序的，所以支持索引与切片，元组的索引与切片操作与列表字符串完全类似，这里我们就不再赘述了

    fruits = ("apple", "banana", "cherry", "date", "elderberry")

print(fruits[0]) 
print(fruits[-1]) 
print(fruits[1:4]) 
print(fruits[:3]) 
print(fruits[2:]) 

    apple
elderberry
('banana', 'cherry', 'date')
('apple', 'banana', 'cherry')
('cherry', 'date', 'elderberry')

    元组也是支持判断成员运算符 in 和 not in 的，使用方法与列表字符串类似：

    fruits = ("apple", "banana", "cherry", "date", "elderberry")

print("banana" in fruits)
print("strawberry" not in fruits)

    True
True

    (2) 元组的应用场景¶

    元组这个数据类型在 Python 中使用非常广泛，有的时候并不是以存储数据的形式出现，而是作为一种语法结构来使用，在以后的 Python 学习中会经常看到。

    比方说，元组可以用来实现多变量赋值，即一次性给多个变量赋值：

    x, y, z = 1, 2, 3

print(x)
print(y)
print(z)

    1
2
3
    • 在这个例子中，等号右边的 1, 2, 3 实际上是一个元组，等同于 (1, 2, 3)
    • 这个元组通过解包的方式把元组中的值依次赋给左边的变量 x, y, z
    • 而等式左边的 x, y, z 实际上也是一个元组，分别接受右边元组中的值

    3. 集合¶

    (1) 集合的基本概念¶

    (a) 集合的定义¶

    集合（set）是 Python 中的另一种组合数据类型，和列表、元组不同的是，集合中的元素是无序的，并且不允许重复。

    集合的概念，和大家在数学上学到的集合是一样的，因此这里大家理解起来会比较容易。

    集合的定义格式是使用大括号 {}，并且用逗号 , 分隔各个元素：

    set1 = {1, 2, 3, 4, 5}
print(set1)
print(type(set1))

    {1, 2, 3, 4, 5}
<class 'set'>

    注意，如果我们定义一个空集合，不能使用 {}，因为 {} 定义的是一个空字典，而不是空集合。 定义空集合的格式是 set()：

    set2 = set()
print(set2)
print(type(set2))

    set()
<class 'set'>

    (b) 集合的特点¶

    首先，和大家在数学上学到的集合一样，集合中的元素是不可重复的

    • 因此如果我们定义一个集合时，包含了重复的元素，Python 会自动帮我们去重
    • 其实去重就是集合的一个重要应用场景
    set3 = {1, 2, 2, 3, 4, 4, 5}
print(set3)

    {1, 2, 3, 4, 5}

    其次，集合中的元素是无序的，因此集合不支持索引与切片操作

    set4 = {1, 2, 3, 4, 5}
# print(set4[0])  # 这行代码会引发 TypeError 错误

    (2) 集合的常用操作¶

    (a) 集合成员运算符¶

    集合和列表、元组、字符串一样，支持成员运算符 in 和 not in，用于判断某个元素是否在集合中：

    set_fruits = {"apple", "banana", "cherry"}

print("banana" in set_fruits)
print("strawberry" not in set_fruits)

    True
True

    (b) 集合的运算¶

    集合支持数学上的一些常见运算：

    • 并集：集合1 | 集合2 或 集合1.union(集合2)，返回一个包含两个集合中所有元素的新集合
    • 交集：集合1 & 集合2 或 集合1.intersection(集合2)，返回一个包含两个集合中共同元素的新集合
    • 差集：集合1 - 集合2 或 集合1.difference(集合2)，返回一个包含在集合1中但不在集合2中的元素的新集合
    set_a = {1, 2, 3, 4, 5}
set_b = {4, 5, 6, 7, 8}

print("Set A:", set_a)
print("Set B:", set_b)
print("Union:", set_a | set_b)
print("Intersection:", set_a & set_b)
print("Difference (A - B):", set_a - set_b)
print("Difference (B - A):", set_b - set_a)

    Set A: {1, 2, 3, 4, 5}
Set B: {4, 5, 6, 7, 8}
Union: {1, 2, 3, 4, 5, 6, 7, 8}
Intersection: {4, 5}
Difference (A - B): {1, 2, 3}
Difference (B - A): {8, 6, 7}

    (c) 集合元素的添加与删除¶

    • 集合.add(元素)：向集合中添加一个元素，如果这个元素已经存在，则不会有任何变化
    • 集合.remove(元素)：从集合中删除一个元素，如果这个元素不存在，则会引发 KeyError 错误
    set5 = {1, 2, 3}
set5.add(4)
set5.add(2)
print(set5)

set5.remove(1)
print(set5)

    {1, 2, 3, 4}
{2, 3, 4}

    4. 字典¶

    (1) 字典的基本概念¶

    字典 (dictionary) 是 Python 中的另一种可变的组合数据类型，用来存储一组键值对 (key-value pairs)

    • 字典的定义格式是使用大括号 {}，并且用冒号 : 分隔键和值，逗号分隔 , 每对键值对，键必须是唯一的，且键必须是不可变的类型，通常使用字符串或数字作为键（也可以是元组，但不能是列表）：
    dict1 = {"name": "Alice", "age": 30, "city": "New York"}
print(dict1)
print(type(dict1))

    {'name': 'Alice', 'age': 30, 'city': 'New York'}
<class 'dict'>

    字典中的值可以是任意类型的数据，包括列表、字典等，我们会在后面看到这样的例子。

    • 如果我们定义一个空字典，可以使用 {}，也可以使用 dict()：
    dict2 = {}
print(dict2)
print(type(dict2))

dict3 = dict()
print(dict3)
print(type(dict3))

    {}
<class 'dict'>
{}
<class 'dict'>

    (2) 字典的基本操作¶

    (a) 访问字典中的值¶

    访问字典中的值，是通过键 (key) 来实现的，格式是 字典[键]：

    dict1 = {"name": "Alice", "age": 30, "city": "New York"}
print(dict1["name"])
print(dict1["age"])
print(dict1["city"])

    Alice
30
New York

    # 以下代码会报 KeyError 错误
# print(dict1["gender"])  # 访问不存在的键会报错

    如果不确定某个键是否存在，可以使用字典的 get() 方法：键存在时返回对应的值，键不存在时返回 None（也可以指定一个默认值），而不会报错：

    print(dict1.get("name"))
print(dict1.get("gender"))
print(dict1.get("gender", "未知"))

    Alice
None
未知

    字典中的值是通过键来访问的，而不是通过位置，因此字典不支持数字索引，也不支持切片操作

    (b) 修改字典中的值¶

    修改字典中的值有两种方式：

    • 直接通过 字典[键] = 新值 的方式更新
    • 使用 字典.update({键: 新值}) 的方式更新
    dict4 = {"name": "David", "age": 35, "city": "San Francisco"}
print(dict4)

dict4["age"] = 36
print(dict4)

dict4.update({"name": "David Johnson"})
print(dict4)

    {'name': 'David', 'age': 35, 'city': 'San Francisco'}
{'name': 'David', 'age': 36, 'city': 'San Francisco'}
{'name': 'David Johnson', 'age': 36, 'city': 'San Francisco'}

    (c) 添加与删除键值对¶

    • 添加键值对的方式和修改是一样的：字典[键] = 值，如果这个键不存在，就会添加一个新的键值对；如果这个键已经存在，就会修改它的值
    • 删除键值对可以使用 del 字典[键]，或者使用 字典.pop(键)，其中 pop() 会同时返回被删除的值
    dict5 = {"name": "Eva", "age": 28}

dict5["city"] = "Paris"
print(dict5)

del dict5["age"]
print(dict5)

city = dict5.pop("city")
print(city)
print(dict5)

    {'name': 'Eva', 'age': 28, 'city': 'Paris'}
{'name': 'Eva', 'city': 'Paris'}
Paris
{'name': 'Eva'}

    (d) 字典的键、值与长度¶

    • in 和 not in 判断的是某个键是否在字典中，而不是值
    • len(字典)：返回字典中键值对的个数
    • 字典.keys()、字典.values()、字典.items()：分别获取字典中所有的键、所有的值、所有的键值对，通常我们会用 list() 把它们转换成列表来查看
    dict6 = {"name": "Alice", "age": 30, "city": "New York"}

print("name" in dict6)
print("Alice" in dict6)
print(len(dict6))

print(list(dict6.keys()))
print(list(dict6.values()))
print(list(dict6.items()))

    True
False
3
['name', 'age', 'city']
['Alice', 30, 'New York']
[('name', 'Alice'), ('age', 30), ('city', 'New York')]

    5. 用组合数据类型表示二维表格¶

    组合数据类型之间可以相互嵌套，我们可以用它们来表示一个二维的表格，这也是数据分析中最常见的数据形式，我们以一个简单的成绩表为例：

    Name Age Score
    Alice 25 95
    Bob 36 88
    Charlie 25 76

    (1) 列表套列表¶

    外层列表的每一个元素是一个内层列表，对应表格中的一行：

    data1 = [
    ["Alice", 25, 95],
    ["Bob", 36, 88],
    ["Charlie", 25, 76]
]

print(data1[1])        # 第2行
print(data1[1][0])     # 第2行第1列

    ['Bob', 36, 88]
Bob

    (2) 字典套列表¶

    字典的每一个键是表格的列名，对应的值是一个列表，存放这一列的所有数据：

    data2 = {
    "Name": ["Alice", "Bob", "Charlie"],
    "Age": [25, 36, 25],
    "Score": [95, 88, 76]
}

print(data2["Name"])       # Name 这一列
print(data2["Name"][1])    # Name 这一列的第2个数据

    ['Alice', 'Bob', 'Charlie']
Bob

    (3) 列表套字典¶

    列表的每一个元素是一个字典，对应表格中的一行，字典的键是列名：

    data3 = [
    {"Name": "Alice", "Age": 25, "Score": 95},
    {"Name": "Bob", "Age": 36, "Score": 88},
    {"Name": "Charlie", "Age": 25, "Score": 76}
]

print(data3[1])            # 第2行
print(data3[1]["Name"])    # 第2行的 Name

    {'Name': 'Bob', 'Age': 36, 'Score': 88}
Bob

    这三种写法表示的是同一张表格，我们要注意它们取值的顺序是不同的：

    • 列表套列表是先选行，再选列；字典套列表是先选列，再选行

    6. 组合数据类型之间的转换¶

    (1) 转换为列表与元组¶

    Python 中可以使用 list() 函数把其他数据类型转换为列表，使用 tuple() 函数把其他数据类型转换为元组：

    • 字符串转为列表后，列表中的每个元素是字符串中的每个字符
    • 字典转为列表后，列表中的每个元素是字典中的每个键，并不会保留值
    • 字典转为元组后，元组中的每个元素是字典中的每个键，并不会保留值
    print(list((1, 2, 3)))
print(list({1, 2, 3}))
print(list({"a": 1, "b": 2}))
print(list("abc"))

    [1, 2, 3]
[1, 2, 3]
['a', 'b']
['a', 'b', 'c']

    print(tuple([1, 2, 3]))
print(tuple({1, 2, 3}))
print(tuple({"a": 1, "b": 2})) 

    (1, 2, 3)
(1, 2, 3)
('a', 'b')

    (2) 转换为集合¶

    Python 中可以使用 set() 函数把其他数据类型转换为集合：

    print(set([1, 2, 3]))
print(set((1, 2, 3)))
print(set({"a": 1, "b": 2}))

    {1, 2, 3}
{1, 2, 3}
{'b', 'a'}

    转换为集合是一个常见的去重操作，例如我们可以把一个列表转换为集合来去除重复的元素：

    # 给list1去重
list1 = [1, 2, 2, 3, 4, 4, 5]
print(list(set(list1)))

    [1, 2, 3, 4, 5]

    # 找出在list2中但不在list3的元素
list2 = [1, 2, 2, 3, 4, 4, 5]
list3 = [2, 4]  
print(list(set(list2) - set(list3)))

    [1, 3, 5]
