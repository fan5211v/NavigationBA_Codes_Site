    Class 2.10 - 引用 Python 模块¶

    1. 模块的引用¶

    (1) 模块引用：使用 import 模块名 的形式¶

    模块（Module） 就是一个包含了函数、变量等内容的 .py 文件，它可以被其他的代码引用，主要分为三类：

    • Python 自带的内置模块，比方说 math、random
    • 需要额外安装的第三方模块，比方说 pandas
    • 我们自己编写的自定义模块，后面会专门介绍

    在 Python 中，我们可以调用大量的内置模块和第三方模块来完成各种各样的功能：

    • 引用的格式是 import 模块名 的形式
    • 调用的格式是 模块名.功能名 的形式

    例如，我们可以使用 Python 内置的 math 模块来进行数学计算：

    import math

print(math.sqrt(16))

    4.0

    (2) 模块引用：使用 from 与 import 语句引用特定功能¶

    还有一种引用的方式是使用 from 与 import 语句来引用模块中的特定功能：

    • 引用格式为 from 模块名 import 功能名，
    • 调用格式为 功能名，注意在这种引用方式下，我们直接使用 功能名 来调用模块中的功能，而不需要再加上 模块名. 前缀
    from math import sqrt

print(sqrt(16))

    4.0

    使用 from 与 import 语句还可以引用模块中的多个功能：

    from math import sqrt, exp, pi
# from math import (sqrt, exp, pi) # 也可以使用括号来把所有功能括起来

print(sqrt(16))
print(exp(1))
print(pi)

    4.0
2.718281828459045
3.141592653589793

    (3) 模块引用：使用 from 与 import 语句引用所有功能¶

    我们还可以使用 from 与 import 语句引用模块中的所有功能：

    • 引用格式为 from 模块名 import *
    • 调用格式为 功能名，同样，在这种引用方式下，我们直接使用 功能名 来调用模块中的功能，而不需要再加上 模块名. 前缀

    我们来尝试引用 math 模块中的所有功能：

    from math import *

print(sqrt(16))
print(exp(1))
print(pi)
print(log(10))

    4.0
2.718281828459045
3.141592653589793
2.302585092994046

    (4) 模块引用方式的小结¶

    目前为止我们讲了以下几种引用模块的方式，我们来做个简单总结：

    引用方式 调用方式 导入内容 备注
    import 模块名 模块名.功能名 导入整个模块 推荐
    from 模块名 import 功能名 功能名 只导入指定的功能 推荐
    from 模块名 import 功能名1, 功能名2 功能名 只导入指定的多个功能 推荐
    from 模块名 import * 功能名 导入模块中的所有功能 不推荐，容易导致命名冲突

    2. 使用 as 关键字起别名¶

    在将模块或功能导入到当前命名空间时，我们还可以使用 as 关键字为模块或功能指定一个别名，有如下的具体形式：

    • import 模块名 as 模块别名：调用时使用 模块别名.功能名
    import math as m

print(m.sqrt(16))

    4.0
    • from 模块名 import 功能名 as 功能别名：调用时使用 功能别名
    from math import sqrt as genhao
print(genhao(16))

from math import exp as e_de_cifang
print(e_de_cifang(1))

    4.0
2.718281828459045
    • 起别名最常见的用途，是给名字比较长的模块起一个简短的别名，比方说 import pandas as pd，还有 import numpy as np

    3. 常用模块¶

    除了 math 模块之外，还有许多在数据分析中常用的模块，本节我们先来介绍 random 模块，再列出数据分析中常用的一些模块，最后来说明一下内置模块与第三方模块的区别。

    (1) random 模块¶

    random 模块可以用来生成随机数，在数据分析中常用来生成测试数据。random 模块中常用的函数有：

    函数 作用
    random.random() 返回一个 0 到 1 之间的随机小数
    random.randint(a, b) 返回一个 a 到 b 之间的随机整数，包含 a 和 b
    random.randrange(start, stop) 返回一个 start 到 stop 之间的随机整数，不包含 stop，用法和 range() 类似
    random.uniform(a, b) 返回一个 a 到 b 之间的随机小数
    random.choice(序列) 从列表等序列中，随机选取一个元素

    每次运行下面的代码，得到的结果都是不一样的：

    import random

print(random.random())
print(random.randint(1, 10))
print(random.randrange(1, 10))
print(random.uniform(1, 100))
print(random.choice(["苹果", "香蕉", "橘子"]))

    0.7796221997172303
1
9
82.9935772788223
苹果

    结合我们学过的列表推导式，可以很方便地生成一组随机的测试数据，比方说，生成 5 个 60 到 100 之间的随机成绩：

    scores = [random.randint(60, 100) for _ in range(5)]
print(scores)

    [65, 82, 63, 61, 70]

    如果希望每次运行都得到相同的随机结果（比方说，为了让别人可以复现我们的结果），可以先使用 random.seed() 设置随机种子，相同的随机种子会得到相同的随机数：

    random.seed(42)
print(random.randint(1, 100))

random.seed(42)
print(random.randint(1, 100))

    82
82

    (2) 数据分析中常用的模块¶

    在数据分析中，最常用的模块有：

    模块 常见的引用方式 作用
    math import math 数学函数
    random import random 随机数的生成
    pandas import pandas as pd 表格数据的处理与分析
    numpy import numpy as np 数组、数值、矩阵计算
    matplotlib import matplotlib.pyplot as plt Python 中最基础的绘图库
    plotnine from plotnine import * 基于图层语法的绘图库，类似 R 中的 ggplot2
    scipy from scipy import stats 科学计算与统计检验
    statsmodels import statsmodels.api as sm 统计建模，比如回归分析
    scikit-learn from sklearn.linear_model import ... 机器学习
    pytorch import torch 深度学习框架
    • 这些模块的别名，比如 pd、np、plt，都是大家约定俗成的写法，起别的名称也不会报错
    • 但是在网上查资料或者看别人的代码时，基本都是这样写的，所以我们也要保持一致

    (3) 内置模块与第三方模块¶

    按照模块的来源，我们可以把它们分为内置模块和第三方模块：

    • 内置模块：Python 安装好之后就自带的模块，不需要额外安装，可以直接引用，比方说 math、random
    • 第三方模块：由其他开发者编写和维护的模块，需要先安装才能使用，比方说 pandas、numpy、matplotlib，我们在 Class 1.2 中已经安装过了
    • 如果引用了一个还没有安装的第三方模块，Python 会报 ModuleNotFoundError 错误，这时就需要先安装这个模块
    • Python 的内置模块数量不多，功能也比较有限，数据分析中的大部分功能，都是由第三方模块提供的
    • 除此之外，我们还可以编写自己的模块，也就是自定义模块，我们下一节来介绍

    4. 自定义模块¶

    事实上，我们自己编写的 .py 文件，也可以像 math、random 一样被引用，这就是自定义模块。我们来动手创建一个：

    • 首先，在当前 Notebook 所在的文件夹中，新建一个名为 my_utils.py 的文件
    • 之后，在这个文件中写入以下内容，这里我们定义了一个变量 c，以及一个计算 (a + b) * (a - b) 的函数 calculate：
    c = 123.456


def calculate(a, b):
    return (a + b) * (a - b)

    有了这个文件之后，我们就可以像引用 math 模块一样，引用 my_utils 模块了：

    import my_utils

print(my_utils.c)
print(my_utils.calculate(5, 3))

    123.456
16

    同样，也可以使用 from 与 import 语句，只引用模块中的特定功能：

    from my_utils import calculate

print(calculate(10, 4))

    84

    在使用自定义模块时，有以下几点需要注意：

    • my_utils.py 文件需要和当前的 Notebook 放在同一个文件夹中，否则 Python 会找不到它
    • 如果我们修改了 my_utils.py 文件，Notebook 并不会自动重新加载它，需要重启内核（Restart）后，再重新运行代码，修改才会生效
    • 自定义模块的文件名，不要和已有的模块重名，比方说，千万不要把自己的文件命名为 random.py 或者 math.py，否则 Python 会引用错误的模块

    5. 包的导入¶

    前面我们介绍的模块，指的是一个 .py 文件。当模块比较多的时候，我们会把相关的多个模块放在同一个文件夹中，这个文件夹就叫做包（Package），也就是说，模块和包的区别是：

    • 模块（Module）：一个 .py 文件
    • 包（Package）：一个文件夹，里面放着多个相关的模块

    包中模块的引用方式如下：

    • 引用包中的某个模块，需要使用点号 . 把包名和模块名连接起来：import 包名.模块名
    • 比方说，matplotlib 是一个绘图的包，pyplot 是这个包中的一个模块，我们就会用到下面这样的引用：
    import matplotlib.pyplot as plt

print(type(plt))

    <class 'module'>
    • 包中的模块通常会配合 as 一起使用，给这个模块起一个简短的别名，之后就可以通过 plt.功能名 来调用模块中的功能

    事实上，随着大家使用得越来越多，会越来越弱化包和模块的区别：

    • 比方说，我们经常会说“引用 pandas 模块”，但是 pandas 其实是一个包
    • 在网上查资料或者看别人的代码时，大家也会发现，很多人并不会严格地区分这两个说法
    • 这是很正常的现象，大家不用太纠结，只要知道它们的引用方式是一样的就可以了
