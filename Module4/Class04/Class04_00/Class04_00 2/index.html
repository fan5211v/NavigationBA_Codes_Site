    Class 4 - SQL 中的嵌套结构¶

    在 SQL 中，我们可以从一个查询结果中继续进行查询，这就是 SQL 中的嵌套结构。嵌套结构可以帮助我们更高效地处理数据。在本章中，我们将介绍 CTE（公共表达式）和子查询两种嵌套结构的使用方法。

    • Class 4.1 - 公共表达式：学习 SQL 中的 CTE（公共表达式）的使用方法，掌握如何使用 CTE 来简化查询。
    • Class 4.2 - 子查询：学习 SQL 中的子查询的使用方法，掌握如何使用子查询来实现复杂的查询需求。
